# Application Context Raja Katsu

## Role Pengguna

Admin:
- Mengelola produk dan harga.
- Melihat laporan.
- Membatalkan transaksi dengan alasan.
- Mengelola pengguna.

Kasir:
- Mencatat penjualan.
- Tidak dapat melihat laporan bisnis tertentu.

## Pencatatan Penjualan

Alur:
1. Pilih produk.
2. Cek pesanan.
3. Simpan transaksi.
4. Sistem mencatat pembayaran dan transaksi.

## Dashboard

Dashboard menampilkan:
- omzet
- modal produk terjual
- laba kotor
- rekap metode pembayaran
- produk terlaris

Laba yang ditampilkan adalah laba kotor:
pendapatan - modal produk.

Bukan laba bersih karena biaya operasional tidak dihitung.

## Riwayat Transaksi

Transaksi yang dibatalkan tidak dihapus.
Admin harus memberikan alasan pembatalan.
